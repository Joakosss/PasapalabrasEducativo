# Instalar PWA en mi escritorio 
**Paso 1 :**
`git clone https://github.com/Joakosss/PasapalabrasEducativo`
**Paso 2:**
`pnpm install`
`pnpm run build`
`pnpm run preview `
Hacemos click y abrimos nuestra aplicacion en el siguiente mensaje:
<img width="265" height="68" alt="image" src="https://github.com/user-attachments/assets/2f16213f-8ed9-4ae0-8a7a-7d69b5a085ef" />
Hacemos click  en el botón de instalar:
<img width="1632" height="44" alt="image" src="https://github.com/user-attachments/assets/946fec72-dd7c-4ff9-a9f3-2ecd5d393989" />
## Una vez finalizado el proceso deberia aparecer en el escritorio y haciendo doble click en otras ocaciones deberia abrir la app.
